# apex3d-bolivia.github.io
Página web de APEx3D

## Pedidos

La pestaña **Pedidos** abre `pedidos.html`, con vistas de **Lista** y **Calendario**. Para ingresar, usa el usuario `apex3d` y la contraseña `apex3d123`.

Los pedidos y los enlaces a los archivos se guardan localmente en el navegador que se esté usando. No necesitan un servicio externo y no se comparten automáticamente entre otros navegadores o dispositivos. El usuario y la contraseña están escritos en el JavaScript público, así que este acceso solo es una barrera informal, no seguridad real. **Descargar copia de pedidos** permite respaldar los registros en un archivo JSON.
