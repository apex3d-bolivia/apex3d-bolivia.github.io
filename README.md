# apex3d-bolivia.github.io
Página web de APEx3D

## Pedidos

La pestaña **Pedidos** abre `pedidos.html`, con vistas de **Lista** y **Calendario**. En el primer acceso, configura tres nombres de usuario y sus contraseñas; luego, cada persona puede ingresar con sus credenciales. Desde **Cambiar usuarios** se pueden reemplazar las tres cuentas.

Los pedidos, los enlaces a los archivos y las credenciales se guardan localmente en el navegador que se esté usando. No necesitan un servicio externo y no se comparten automáticamente entre otros navegadores o dispositivos. El acceso con contraseña es una barrera sencilla de uso, no seguridad real: los datos del sitio estático y su almacenamiento local no deben considerarse confidenciales. **Descargar copia de pedidos** permite respaldar los registros en un archivo JSON.
